Sin ejecutar la siguiente secuencia de comandos, determine lo que imprime

Código

var fila = 10;
var columna;

while ( fila >= 1)
{
  columna = 1;
  document.write("<p>");

  while (columna <= 10 )
  {
    document.write(fila % 2 == 1 ? "<" : ">");
    ++columna;
    } //end while

    --fila;
    document.write("</p>");
} // end while

Lo que va a hacer

Lo que hace es hacer bucles anidados e impormir 10 filas, pero cada fila va a tener un < o un > dependiendo si es par o impar.
En caso de ser impar va a imprimir un <, en caso de ser par imprimirá un >
