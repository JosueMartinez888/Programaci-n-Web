Encuentre el error en cada uno de los siguientes segmentos de código, puede haber más de uno

a)
Código
For ( x = 100, x >= 1, ++x )   document.writeln(x); Error
En el for se separa con ';' y For es en minúsculas

b) El sigueinte código debe imprimirse sin importar si el valor entero es par o impar
Código
switch ( valor % 2)
{
  case 0:
    document.writeln("Entero par");
  case 1:
    document.writeln("Entero impar")
}
Error
Falto el break para romper los casos

c) El siguiente código debe imprimir los enteros impares del 19 al 1
Código
for ( x = 19; x >=1; x += 2 )
  document.writeln(x);
Error
Dice que x se va a ir sumando de 2 en 2, pero si comienza de 19 tiene que ir al revés, tiene que ser x-=2 para que vaya decrementando

d) El siguinete código debe imprimr los enteros pares del 2 al 100
Código
contador = 2;
do{
  document.writeln( contador );
   contador += 2;
} While (contador < 100);
Error
El While es en minúsculas, y no debe de ser '< 100', sino '<= 100' para que también cuenta el 100
