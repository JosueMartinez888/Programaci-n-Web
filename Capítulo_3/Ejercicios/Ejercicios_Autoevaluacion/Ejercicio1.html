a) El tipo input color permite al usuario introducir un color. Al momento de escribir este libro, la mayoría de los navegadores despliegan el tipo input color como un campo de texto donde el usuario puede introducir un ___valor hexadecimal___

b) El atributo ___placeholder___ nos permite colocar texto temporal en un campo de texto.

c) Si desea anular la validación, puede agregar el atributo formnovalidate al tipo input ___submit___

d) El atributo ___required___ obliga al usuario a introducir un valor antes de enviar el formulario.

e) Por lo general se muestra el control ___range___ para el tipo input number e incluye solo números válidos

f) El tipo input ___time___ permite al usuario introducir una hora, minuto y segundo y fracción de segundo

g) El elemento ___datalist___ proporciona opciones de entrada para un elemento input text.

h) El elemento ___article describe el contenido que está separado del contenido principal de la página y que posiblemente podría utilizarse o distribuirse en otro parte, como un artículo de noticias, mensaje de foro o entrada de blog.

i) El elemento ___footer___ describe el texto que por lo general aparece en la parte inferior del contenido o de un elemento section.

j) El elemento ___wbr___ indica el lugar apropiado para dividir una palabra cuando el texto se ajusta en varias líleas
